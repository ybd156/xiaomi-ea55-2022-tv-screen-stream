记录做过的技术取舍，避免后人重复推导或推翻已否决的方案。

## 格式

每条 ADR 包含：

- **状态**：已接受 / 已拒绝 / 已废弃
- **背景**：为什么要做这个决定
- **决策**：选了什么
- **后果**：正面和负面
- 如果有验证过程，写清楚做了什么、结果是什么

## 原则

1. 只在**有证据**的情况下写结论。没验证的说"未验证"。
2. 已否决的方案也要写下来 —— 否则后人会重新试一遍。
3. 一个决定一条，不要合并。
